# TomoNode Releases

TomoNodeの署名済みWindows更新ファイル専用リポジトリです。

Each release contains only the signed Windows installer, its `.sig` file, and `latest.json` for the in-app updater. Source code, server settings, worlds, credentials, logs, and the signing private key are not stored here.

TomoNode is an unofficial community tool and is not affiliated with Mojang, Microsoft, Pocketpair, or Valve.
